# Titia V1.4 增量更新

- 今日 Banner：经用户授权定位后，直接从 Open-Meteo 获取当前天气、温度和当前小时紫外线指数；经纬度不写入数据库。
- 周期：新增可切月日历，经期、预测期和今天采用独立标记。
- 倒数日：改为横向信息卡；无效日期显示“待设置日期”，不再出现 `NaN`。
- 密码箱：设置与解锁改为 App 内弹窗，继续使用 PBKDF2 + AES-GCM，不保存主密码明文。
- 小账：增加账单长按/按钮批量模式、批量删除/分类/账户；资产和负债分区；分类支持新增、改名和删除。
- 时光：侧栏增加“灵光一闪”，支持标签筛选、历史列表、编辑、删除及图片 Blob 持久化；旧 `sparks` 自动兼容为新记录。
- 关系：感动瞬间与矛盾复盘成为两个可切换、按真实 `type` 字段筛选的板块。

## 数据变化

`AppData` 新增 `sparkNotes`；IndexedDB schema v4 新增 `sparkMedia` 表。旧数据和旧备份仍可载入，既有字段不删除。

## 验证

Vitest 22 个文件、100 个测试通过；ESLint 通过；Vite 生产构建通过。
