# 数据迁移与灵光入口 V1.2

- “我呀 → 数据管理”支持本地 AES-GCM 加密的一键迁移链接，数据只放在 URL Fragment，不进入服务器日志。
- 导入前自动创建完整 IndexedDB 恢复快照；所有集合按 ID 合并，已有记录不会被覆盖。
- 高级恢复兼容新版备份和旧版 `version: 1 / tables` 备份，图片随备份本地迁移。
- 标准二维码容量有限：仅当完整迁移链接可无损容纳时显示二维码；数据过大时使用复制链接或高级恢复，不会静默删图。
- 灵光一闪按钮默认 80% 透明度，长按 1 秒后可拖动和调节透明度，释放吸附边缘并避开状态栏、底部导航与安全区域。
- 悬浮位置与透明度保存在 IndexedDB 的 `userPreferences.floatingButton`，并兼容旧版 `preferences.sparkFab`。
