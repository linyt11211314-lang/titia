# Titia V1.1 Incremental Optimization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add real-data ledger overviews, hierarchical categories, spreadsheet import/export, an independent OCR draft flow, corrected icons, and persistent spark-button controls without redesigning Titia.

**Architecture:** Preserve the current React shell and Dexie state-row store. Add a V2 normalizer and a pure ledger utility module, then connect focused UI components to those tested interfaces.

**Tech Stack:** React 19, TypeScript, Dexie, SheetJS, Vitest, Testing Library, Vite, GitHub Pages.

## Global Constraints

- Do not rewrite the App, visual system, bottom navigation, or existing persistence mechanism.
- Every summary and import result must derive from or write to `AppData`.
- Do not seed new user categories; migrate existing category names unchanged.
- Candidate imports and OCR results require confirmation before becoming confirmed transactions.
