# Titia UI / 交互优化 V1.3–V1.4 设计

## 目标

在不改变天空、云朵、玻璃卡片、圆角和底部五栏导航的前提下，补齐周期月历、倒数日容错、密码箱弹窗、小账批量管理与分类编辑，并将“灵光一闪”升级为时光中的完整本地模块。

## 兼容策略

- `AppData.version` 升至 4，但保留旧 `sparks`、分类、密码箱和迁移包读取。
- 旧 `sparks` 首次载入时规范化为 `sparkNotes`；不删除原字段，避免旧备份丢失。
- 新增 `sparkMedia` IndexedDB 表保存图片 Blob，迁移包同步包含图片；所有内容仍只在本机处理。
- 分类编辑直接修改 `ledgerCategories`，并从叶子分类同步 `categories`，不再在每次启动时覆盖用户修改。
- 账户余额继续由已确认交易推导；批量删除同时删除附件，余额自然回滚。

## 页面与交互

1. 周期页：当前周期卡下方加入可切月日历，历史经期粉色、预测期浅粉、当天蓝色描边；按钮和水平滑动均可切月。
2. 倒数日：统一横向三栏卡片，日期无效时显示“待设置日期”，计算函数不返回 `NaN`。
3. 密码箱：用受控弹窗完成创建主密码、确认与解锁；沿用 PBKDF2 + AES-GCM，绝不持久化明文。
4. 账单：长按行进入选择模式，也提供明确的“批量管理”入口；支持批量删除、分类和账户修改。
5. 资产：分为资产与负债两组，按账户类型映射。
6. 分类：收入/支出独立状态下支持新增一级/二级、重命名和删除；删除有交易引用的分类前提示。
7. 灵光一闪：加入时光侧栏；支持标签筛选、列表、详情、编辑、删除、图片附件。全局悬浮按钮点击新增，长按进入拖动/透明度设置，沿用 V1.2 的吸边和位置持久化。
8. 布局：标题/总览留在固定容器，只有内容区滚动，并保留底部安全间距。

## 测试边界

纯函数覆盖日期计算、月历标记、账户分组、分类变更和 Spark 兼容迁移；组件测试覆盖批量账单、密码弹窗、Spark 筛选/CRUD/图片；最终执行全量 Vitest、ESLint、Vite build 与线上冒烟。
