# Titia 时序 V1.1 增量优化设计

## 范围与约束

V1.1 保留现有 `TitiaApp`、天空背景、云朵、圆角卡片、iOS 视觉、底部五项导航和 Dexie 单状态行存储。改动只扩展小账、时光侧栏和灵光一闪，不重写页面，不引入服务器或临时模拟数据。

## 数据模型

`AppData.version` 升为 2，新增：

- `ledgerCategories: LedgerCategory[]`：`id`、`name`、`type`、可选 `parentId`，表达收入/支出和一级/二级关系。
- `preferences.sparkFab`：保存悬浮按钮 `x`、`y`、`opacity`。
- `backupMeta.lastSpreadsheetExportAt`：记录最近一次表格导出时间。

读取 V1 数据时进行内存规范化：旧 `categories` 字符串原样映射为一级支出分类，不创建示例子分类；保存时写入 V2。交易仍保留原有 `category` 字符串，避免破坏历史数据和导入导出。

## 小账与总览

小账侧栏使用独立图标映射：首页🏠、账单🧾、资产💰、分析📊、分类🗂️、导入导出📥、AI识别✨。日记与关系分别使用📖和💙。每个小账二级页面在 `section-main` 内使用非滚动总览卡，内容列表单独滚动。汇总全部由当前 `transactions`、`accounts`、`budgets` 和分类数据实时计算。

## 表格数据中心

使用 SheetJS 在浏览器本地生成和解析 `.xlsx`，工作簿包含账单、分类、账户、预算、资产五个工作表；CSV 作为账单快速导出。Excel 导入只读取工作簿中的“账单”或首个表，自动匹配中英文字段名，规范化日期、金额、收入支出、分类、账户和备注。解析后先展示成功/收入/支出/错误数量和预览，用户确认后才写入 `transactions`，且来源标记为 `import`。

## AI 识别中心

AI识别是独立小账入口。用户选择截图后先展示本地预览；若浏览器提供本地 `TextDetector`，读取文字并用同一账单解析器生成候选草稿。无本地 OCR 能力时明确提示，并允许用户粘贴识别文字继续生成草稿。所有候选均为 `reviewStatus: candidate`，用户确认后转为 `confirmed` 写入真实账单。

## 灵光一闪

默认透明度 70%。普通点击打开现有灵光表单；按住一秒进入编辑面板。编辑状态可拖动按钮并选择 20/40/60/80/100% 透明度，保存后写入 IndexedDB。位置限制在视口范围且不得进入底部导航安全区。

## 测试与验收

- 数据规范化测试覆盖 V1→V2、分类保留和偏好默认值。
- 账务工具测试覆盖月度汇总、资产负债、分析环比、导入字段识别和草稿生成。
- 组件测试覆盖二级总览、专属图标、分类收支切换、独立 AI 入口和灵光设置保存。
- 运行单元测试、ESLint、根路径及 `/titia/` 子路径生产构建，推送后等待 GitHub Pages 成功并访问公网地址验证。
