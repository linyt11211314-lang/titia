# Titia 时序 V2.0 增量优化设计

## 目标与边界

在现有 React、Dexie/IndexedDB、PWA 和 GitHub Pages 架构上增量升级。保留浅蓝天空、云朵、圆角卡片与五项底部导航；不覆盖已有记录，不引入登录、服务器或模拟数据。

## 实施策略

采用“兼容性数据扩展 + 独立功能组件 + 统一设计令牌”的方案。已有迁移、智能识别、日期聚合、附件和分类规则能力继续复用；新增字段全部可选并由 `normalizeAppData` 补默认值，旧数据原样可读。大功能拆分到独立组件与纯函数，避免继续扩大主页面文件。

## 数据与交互

- 用户偏好扩展主题、默认账户；账户扩展类型和资产/负债/借贷分组；关系记录扩展图片 ID；倒数日兼容旧字段并增加足迹/期待语义。
- 图片统一存入 IndexedDB Blob 表，表单采用多选、预览、删除，正文数据仅保存图片 ID。
- 待办完成后从未完成区消失；购物购买后同时从今日与待买区消失，但数据仍保留在已买记录。
- 灵光一闪使用同一编辑器完成新增和编辑，标题可空、标签与一级分类一致。
- 密码箱离开页面立即清除内存中的解锁密钥与明文。
- 小账保持真实交易数组为唯一来源：模板导入映射两级分类；预算可编辑删除；分析按范围计算；账户分区并可设置默认账户；识别仍须审核确认。
- 快捷指令以 URL 入口和用户主动“识别剪贴板”为主，尊重 iOS 对剪贴板权限的限制。

## 视觉与移动端

通过 CSS 变量统一紧凑间距、固定数字字号和卡片槽位；金额由格式化函数缩写为万/亿，禁止换行。顶部概览不横向滚动，底部导航贴合安全区。二级全屏页面支持边缘右滑返回。图片控件统一为方形“＋”网格。

## 兼容与验证

IndexedDB 版本只增不删；导入前保留恢复快照；现有 JSON/迁移链接继续有效。使用 Vitest 覆盖数据兼容、模板映射、日期计算、主题、预算、账户、智能识别及关键 UI，再执行 ESLint、生产构建和 GitHub Pages 部署验证。
